# InteriorArts

A responsive editorial website for InteriorArts, an independent interior architecture and design studio.

## Run locally

Open `index.html` directly in a browser. The project is intentionally dependency-free and uses remote Unsplash photography plus Google Fonts for its visual assets.

## Included

- Responsive desktop and mobile layouts
- Mobile navigation toggle
- Filterable selected-work grid
- Scroll reveal animations
- Accessible labels and semantic sections
